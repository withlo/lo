The mark, wordmark, lockup and app icon live in `brand/logo/` and `brand/icon/`. Each file is one
fixed ink: `-chalk` files are chalk (#FBF8F2) for dark grounds (`lo-bg` in Lo Glow Dark), `-ink`
files are ink (#15161D) for light grounds. The app icon is the chalk mark on an ink rounded square.
Never recolor them, never put them in the accent, and never add shadows, glows or outlines. Use the
files in `brand/`, never a copy.
