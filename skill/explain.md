description:
  Writes or updates the Lo overview of a GitHub pull request, the explanation Lo shows its reviewers
  beside the diff, then checks it and pushes it to the pull request's refs/lo/pr ref. Use it only
  when asked to write, update, fix or explain a Lo overview of a pull request, such as someone
  else's. Never start it by yourself after opening or pushing to a pull request; in a repository
  with the lo-overview skill, that one does.
